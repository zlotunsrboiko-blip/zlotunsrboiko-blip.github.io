# MKE SHOP и ROBOTICVN SHOP

В «Пуле товаров» показаны отдельные кошельки с временем проверки. Обновление — раз в минуту, пока открыт пул, или кнопкой «Обновить баланс». USD и VND не складываются; ошибка связи не заменяется нулём.

Категория → «Настроить» → «Автозакупка, когда свой пул пуст»: выберите магазин, затем его товар/вариант. Прежние настройки MKE сохранены. Для ROBOTICVN нужен секрет `ROBOTICVN_API_KEY` в Cloudflare; для MKE остаётся `MKE_API_KEY`. Ключи поставщиков не передаются браузеру.

Сначала используется свой запас. Если его не хватает, сервис покупает выбранный товар у указанного поставщика. Для ROBOTICVN перед покупкой проверяются цена, остаток и кошелёк. После получения всех данных они автоматически передаются в Маркет. Время выдачи поставщика не гарантируется. Готовность карточки проверяется для одной единицы; итоговое количество — при заказе. API ROBOTICVN не поддерживает ограничение цены при её изменении между проверкой и оплатой.

ROBOTICVN не документирует защиту от повторной покупки. Номер закупки сохраняется для последующих проверок. При неизвестном результате оплаты новая покупка блокируется: проверьте её в кабинете ROBOTICVN и журнале приложения. При подтверждённом отказе без покупки, например недостатке средств, проверка повторяется с задержкой. При пустом кошельке покупка не выполняется. Полученные данные хранятся зашифрованными, чтобы ожидание другой позиции не вызывало повторную закупку.

Фильтры «Режим» и «Закупка» допускают несколько значений; применяются к карточкам и таблице товаров. Фильтр магазина показывает настройку закупки категории, а не происхождение вручную загруженного товара. Значки: ↻ — универсальный, 1× — уникальный, M/R — магазин, ⌂ — свой пул. Подсказки доступны при наведении и фокусе.

Каталог ROBOTICVN загружается страницами; «Ещё товары ROBOTICVN SHOP» открывает следующие варианты. Документация: https://api.roboticvn.com/api/v2/docs . Реальные тестовые покупки при подготовке обновления не выполнялись.
