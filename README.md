# Цифровые продажи — версия 3

Пул аккаунтов и CDK по категориям, учёт выдач, фоновые заказы и зеркало в Google Таблицах. Основная инструкция: [SETUP.md](SETUP.md).

Раздельные форматы пула и закупки, приоритет выдачи и правила синхронизации остатков: [STOCK-SYNC.md](STOCK-SYNC.md).

Сайт GitHub Pages по-прежнему публикуется одним файлом index.html. Пересборка: npm run build. Демо: npm run demo. Проверки: npm test.

Для запуска нужны D1, миграция и секреты Cloudflare. Автовыдача по умолчанию отключена до настройки. Фактические выплаты после комиссий пока вводятся вручную из финансового отчёта.
